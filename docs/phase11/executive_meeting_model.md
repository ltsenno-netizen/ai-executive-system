# Phase 11: AI Executive Meeting Simulation

## 目的

AIが経営幹部として月次資料をまとめ、課題・改善・投資判断を説明し、経営者が承認・却下・修正・保留を行う経営会議レイヤーを構築します。

## 議題生成ロジック

- PL/P/Lの損益サマリー
- KPIの達成状況と見直しポイント
- オペレーション上のタスク・インシデント
- 検出された課題と改善アクション
- 事業ポートフォリオの投資判断

各情報を `MeetingAgendaItem` に集約し、AIが推奨コメントと影響予測を生成します。

## AI推奨の生成方法

- 各議題に対して、現状とトレードオフを踏まえた短い推奨文を作成
- 投資判断は `Portfolio` 議題で特に明示
- 課題解決は `Issues` / `Improvements` 議題で優先度化

## 経営者の意思決定がシミュレーションに与える影響

- `Approve` は意図した効果を翌月予測に反映
- `Reject` は効果を無効化
- `Modify` は軽微に調整して 80% の効果を適用
- `Hold` は次月に持ち越し、今回の影響は適用しない

## 次月予測の仕組み

- `simulate-month-full(month+1)` で翌月の基礎予測を取得
- 経営会議の意思決定効果を加味して `next_month_projection` を計算
- 予測には収益、利益、利益率、主要KPIを含む

## 実際の経営会議の流れ

1. AIが月次議題を提示
2. 経営者が各議題に対して承認・却下・修正・保留を決定
3. システムが意思決定を適用し、翌月の予測に反映
4. 会議結果を状態として保存し、ダッシュボードに反映
