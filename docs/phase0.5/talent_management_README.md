# タレントマネジメント部 仮想オフィス構築ガイド

## 部門ミッション

### タレントマネジメント部 Mission Statement
「タレントの価値最大化を通じて、エンターテイメント産業の発展に貢献する」

### 主要Objectives
1. タレントのキャリア開発と市場価値向上
2. マネジメント体制の最適化と人材育成
3. 契約条件の適正化とリスク管理
4. 収益性向上を通じた事業貢献

### 部門レベルKPI
- **タレントLTV向上率**: 前年比120%以上

### ユニット別KPI
- **マネージャー課**: タレント満足度95%、育成完了率90%

- **タレント契約課**: 契約更新率95%、法的リスクゼロ

## RACIテンプレ

### 標準RACIマトリックス

| プロセス | タレントマネジメント部長 | マネージャー課長 | 契約課長 | 選手マネジメント課長 | 各担当者 |
|----------|-------------------------|------------------|----------|---------------------|----------|
| タレント獲得 | A | C | I | I | R |
| マネージャー割当 | A | R | I | I | C |
| 契約交渉 | A | I | R | I | C |
| キャリア開発 | A | R | C | C | I |

**凡例**: A=Accountable(責任者), R=Responsible(実行者), C=Consulted(相談者), I=Informed(報告先)

## 運用ルール

### 1. インバスケット運用
- 毎朝9:00に前日分のインバスケットを確認
- High優先度タスクは当日中に着手
- タスク割当は担当者のスキルと負荷を考慮

### 2. インシデント対応フロー
1. 発生即時: 担当リーダーへ報告
2. 初動対応: 15分以内に暫定対応策実施
3. エスカレーション: Critical/Highは部長判断
4. 事後対応: 原因分析と再発防止策立案

### 3. メンバー育成サイクル
- 四半期毎のスキル評価
- 年2回のキャリア面談
- 異動希望の積極的検討

### 4. 契約管理ルール
- 契約更新は6ヶ月前から着手
- 条件交渉はデータに基づく根拠提示
- 法的レビューは全契約で必須

## 品質管理基準

### タスク完了基準
- High優先度: 100%正確性、期限厳守
- Medium優先度: 95%以上正確性、1日以内の遅延許容
- Low優先度: 90%以上正確性、3日以内の遅延許容

### インシデント対応基準
- Critical: 即時対応、1時間以内に部長報告
- High: 4時間以内に初動対応、1日以内に解決
- Medium: 1日以内に初動対応、1週間以内に解決
- Low: 3日以内に初動対応、2週間以内に解決
