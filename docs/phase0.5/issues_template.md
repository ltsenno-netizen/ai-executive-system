## Issues 生成ルール

### 自動生成トリガー
- Phase 0.5開始時
- 新規ユニット追加時
- プロセス変更時

### 優先度設定基準
- **High**: システム基盤に関わるもの
- **Medium**: 機能拡張に関わるもの
- **Low**: 改善・最適化に関わるもの

### Assignee 自動割当
- 部長判断が必要なもの: タレントマネジメント部長
- 専門知識が必要なもの: 該当部門の専門家
- 技術的なもの: デジタル部または開発担当

### 完了条件の共通項目
- [ ] ドキュメント化完了
- [ ] 関係者レビュー完了
- [ ] テスト実施完了
- [ ] 本番反映完了

## 進捗管理

### ステータス定義
- **Open**: Issue作成済み、着手待ち
- **In Progress**: 作業中
- **Review**: レビュー中
- **Closed**: 完了

### 定期レビュー
- **日次**: High優先度Issuesの進捗確認
- **週次**: 全Issuesの進捗レビュー
- **月次**: Phase全体の進捗評価

### エスカレーション基準
- 期限超過3日: 自動通知
- 期限超過1週間: 上席判断
- ブロック要因発生: 即時報告
